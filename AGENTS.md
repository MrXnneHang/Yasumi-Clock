# Agent Instructions

## Pull requests

- Read `.github/PULL_REQUEST_TEMPLATE.md` before creating or editing a pull request.
- Keep the template's comments and sections in the pull request body; fill in `## 动机`, `## 解决方案`, and `## 类型` rather than replacing the template with an ad-hoc summary.
- Select every applicable type checkbox, and use a gitmoji-prefixed pull-request title.
- Include relevant issue or design-decision references when they exist.
- State the exact verification commands run and any known verification gap.

## Git workflow

- Use `dev` as the base branch unless the change belongs to an explicitly documented stack.
- Do not commit unrelated formatting drift or generated artifacts.
- Keep the working tree clean after committing, pushing, or creating a pull request.
